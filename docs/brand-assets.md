# Command Center icon

Version 0.24.0 replaces the detailed control-tower illustration in the header
and browser favicon with a simple cyan tower and two signal arcs. The same
square PNG is used in both places: `src/assets/command-center-icon.png`.
The opaque dark graphite background keeps the small mark clean against the
application header. The earlier illustration remains available in Git history.

The image was generated with the built-in image-generation tool and inspected
before integration. It is a branding asset, not a new UI dependency.

Generation prompt:

> Square app icon for Command Center NG. Extremely simple geometric airport
> control-tower pictogram centered on a SOLID FLAT DARK GRAPHITE BACKGROUND
> (#101824) filling the entire canvas edge to edge. One clean cyan (#00d4dc)
> solid trapezoid cab with a short thick central stem below and two thick cyan
> signal arcs above, generous margins. Like a minimal vector UI glyph. Smooth
> clean edges. No gradients, no textures, no noise, no speckles, no lighting,
> no glow, no shadows, no outlines, no tiny details, no text, no rounded tile
> border. Full solid opaque dark background, not transparent. Crisp flat
> geometric icon.
